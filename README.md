# 星枢 - 智能戒指应用

基于 UniApp 开发的智能戒指控制移动应用，支持 Android 和 iOS 双平台。

## 应用介绍

星枢是一款配合智能戒指使用的移动应用，通过蓝牙连接戒指设备，实现健康数据监测、设备控制等功能。

## 主要功能

- **蓝牙连接** - 支持通过蓝牙连接智能戒指设备
- **产品展示** - 展示智能戒指产品信息和详情
- **设备控制** - 基座控制功能，管理戒指设备
- **数据监测** - 实时查看戒指采集的健康数据
- **个人中心** - 用户账户管理和设置

## 页面结构

| 页面 | 说明 |
|------|------|
| 登录页 | 用户登录入口 |
| 产品页 | 产品展示与详情 |
| 基座控制 | 戒指设备控制中心 |
| 我的 | 个人中心主页 |
| 设备页 | 设备列表与管理 |
| 戒指页 | 戒指详情与数据展示 |
| 设置页 | 应用设置选项 |
| 关于页 | 应用相关信息 |

## 技术栈

- **框架**: UniApp
- **平台**: Android / iOS
- **通信**: 蓝牙 BLE
- **样式**: Vue 组件化开发

## 运行项目

### 环境要求

- HBuilderX 编辑器
- Android Studio（Android 开发）
- Xcode（iOS 开发）
- Node.js（可选，用于 CLI 模式）

### 运行方式

1. **推荐方式**：使用 HBuilderX 打开项目目录，选择运行到手机或浏览器
2. **CLI 模式**：
   ```bash
   npm install
   npm run dev:%PLATFORM%
   npm run build:%PLATFORM%
   ```
